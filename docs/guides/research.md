# Research and Agent guide

## Research authority

FinAgent research is deterministic after candidate proposal. The Agent may propose bounded hypotheses/features, but data chronology, factor statistics, robust gates, model calibration, portfolio construction and execution remain core-owned.

## Candidate generation

Three conceptual sources are used in the U.S. program:

```text
manual        fixed human-designed candidates
programmatic  bounded deterministic/randomized search
Agent         LLM-generated bounded candidates
```

All accepted/searched candidates remain auditable. Invalid/failed attempts are not erased when the experiment contract includes them in the search budget/denominator.

## Hidden reasoning

FinAgent does not persist or display hidden chain-of-thought. Audit may store explicit prompts/responses when configured, generated code, validation/repair events, model/provider identifiers, timing and token/cost metadata.

## Agent value

Do not infer Agent value from a successful Agent run. US-A0 compares equal-budget arms and repeated runs. The Agent may be reduced to an optional hypothesis interface if it does not improve robust candidate quality, discovery efficiency or useful novelty.

## Robust research

For intraday data, ordinary IID assumptions are insufficient. Formal programs use time-aware walk-forward/purging, HAC, block/session bootstrap, frozen direction/selection and multiplicity control.

A result may validly terminate with `NO_ROBUST_FACTOR_FAMILY`. That is a successful research-platform terminal and a stop condition for strategy deployment, not an exception to hide.

## Workbench research views

The Workbench renders evidence generated by the research core. Factor/strategy charts do not reconstruct missing statistics or financial series in React. Agent chronology is shown only when explicit generation-event evidence exists.
